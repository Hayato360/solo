## Issues Encountered

- **Player.Character reassignment destroys the old model** → detach body into a fresh Model before swapping.
- **Swap detach tripped the Humanoid into FallingDown / neck death** → `HumanoidUtil` + `RequiresNeck=false` on both server and client.
- **Camera didn't follow reassigned characters** → `CameraController`.
- **AI rigs auto-owned by the player** → forced server ownership.
- **Init/Start ordering bug:** HunterAIService missed the first party → signal subscriptions go in `Init`.
- **One client syntax error (line starting with `(`) killed every controller** → bootstraps now pcall require/Init.
- **Gate prompt placed 9.5 studs up was unreliable** → moved to a chest-height anchor.
- **Gate flicker not running (Portal streamed after the model)** → Atomic streaming + lazy portal lookup.
- **Dungeon entrance spawn was 7 studs from the Leave prompt** → moved to 21 studs.
- **MCP limitations:**
  - Can't `require` game modules or fire remotes from `execute_luau`.
  - Simulated input can't press key `1`.
  - Can't parent models containing scripts (the `Animate` LocalScript) in Edit, so rigs are generated at runtime.
- **The Death Box (35,0,0) sits on the spawn → GateSpawn_1 line;** my test navigation killed Kang there.
- **The user was playing in the same playtest while I tested;** several "mystery" swaps and exits were user input (confirmed via input logging).
- **Open design questions** (in sync_task): shadow soldiers, multiplayer AI companions, base ownership, stability timing, Healer weakness in solo.

### Issues Encountered

- **Codex floor bug:** Gates stopped at 5% forever, so breaks never started. Fixed as above.
- **Same-frame race:** several Gates hitting 0% in one Heartbeat each fired `GateStabilityZero`; the fallback would eject players from those Gates. Fixed by checking `CanBreak()` per gate.
- **A remote named `Changed` inside a folder** collides with `Instance.Changed` (`folder.Changed` returns the event), so `IncrementStat` errored. Renamed to `KeyChanged`.
- **Permission classifier** blocked a code edit mid-task, because of the earlier "don't touch code, Codex time" rule; the user then explicitly chose Claude to do the code.
- **MCP limits:**
  - `execute_luau` can't `require` game modules (capability error), which is why `DebugService` exists.
  - It can't create/reparent scripts into `StarterPlayerScripts`; use `multi_edit` with `className`.
  - Mouse clicks by screen coordinate don't line up; click by `instance_path` (name the target instances first).
  - Paths with duplicate names ("Frame") fail.
  - Roblox's player list (CoreGui) can block clicks.
- **"trying to set locked parent!"** engine warnings appear during strong Dungeon Breaks. Not reproduced by killing a dummy, guard or Hunter directly; harmless, source not found yet.
- **User played in the same Studio session** while tests ran (claimed a quest themselves), so automated clicking was stopped.
