# Session AI Logs - Instructions for AI Agents

Welcome! If you are an AI assistant reading this, you are in the `Session-AI_logs` directory for **Dungeon Summon**. This directory is designed to help maintain continuity and context across different AI sessions, tools, and platforms.

## Directory Structure

*   `/AI-Sync/sync_log.md`: **Read this first.** This is the master index. It contains a chronological table of all work done by any AI on this project.
*   `/AI-Sync/sync_task.md`: The master cross-session task tracker (Done / In Progress / To Do).
*   `/Claude/`: Contains detailed session logs generated by Claude.
*   `/[Other AI Names]/`: (Create as needed) Contains detailed session logs generated by other AI assistants (e.g., Gemini, ChatGPT, Copilot).

## Standard Operating Procedure (SOP) for AI Agents

1.  **Upon Initialization:**
    *   Read the `AI-Sync/sync_log.md` file to get a high-level overview of the most recent changes made to the project.
    *   Read `AI-Sync/sync_task.md` to understand pending and in-progress work.
    *   If you need more details about a specific change, follow the file path provided in the `Link to Details` column to read the specific session log.

2.  **During Your Session:**
    *   Perform your tasks as instructed by the user.

3.  **Before Ending Your Session / Upon User Request:**
    *   **Create a Session Log:** Create a markdown file in your designated folder (e.g., `/Claude/session_YYYY-MM-DD.md`) detailing exactly what files you modified, what systems you researched/designed, and what design decisions were made.
    *   **Update the Sync Log:** Append a new row to the table in `AI-Sync/sync_log.md` containing the **real, current system time (YYYY-MM-DD HH:mm)**, your identity, a brief 1-sentence summary of your work, and the relative path to the session log you just created. **Do not use placeholder times.**
    *   **Update the Task Tracker:** Move completed items in `AI-Sync/sync_task.md` to Done, and add any newly discovered tasks.
